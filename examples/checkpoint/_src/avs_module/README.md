# Содержимое архива

- `checkpoint.qsp` — оригинальный пример механизма чекпоинтов от Nex'а с комментариями.
- `avs_checkpoints.qsp` — пример от Aleks Versus. По сути то же, что и предыдущий, но с неколько иным значением переменных.
- `avs_checkpoints.png` — иллюстрация блок-схемы примера от Aleks Versus.
- `avs_checkpoints.excalidraw` — то же самое, но для ExcaliDraw.
